# 🏰 Torre do Destino

**Torre do Destino** é um RPG de batalha por turnos desenvolvido em **JavaScript**, no qual o jogador deve enfrentar diferentes inimigos enquanto avança pelos andares de uma torre.

Durante a jornada, o jogador pode evoluir seu personagem, escolher atributos, utilizar equipamentos e enfrentar inimigos cada vez mais fortes.

## 🎮 Sobre o jogo

O jogador começa sua aventura escolhendo e desenvolvendo seu personagem. A cada andar da torre, um novo inimigo aparece para ser enfrentado.

Durante as batalhas, é necessário escolher estratégias para derrotar os inimigos e continuar avançando.

Quanto maior o andar, maior é a dificuldade dos inimigos.

## ⚔️ Funcionalidades

* 🏰 Sistema de progressão por andares
* ⚔️ Batalhas por turnos
* 👤 Diferentes classes de personagem
* 📊 Sistema de atributos
* ❤️ Sistema de vida (HP)
* 🗡️ Sistema de armas e equipamentos
* 🛡️ Sistema de defesa
* 💥 Sistema de dano
* 🎯 Acertos críticos
* 🏃 Sistema de fuga
* 🪙 Sistema de moedas e recompensas
* ⬆️ Evolução do personagem
* ❤️ Regeneração de HP
* 👹 Inimigos com diferentes atributos
* 📈 Aumento da dificuldade conforme o jogador avança

## 🛠️ Tecnologias utilizadas

* **JavaScript**
* `prompt()` para interação com o jogador
* `console.log()` para exibição das informações

## 🎯 Objetivo

O objetivo é avançar o máximo possível pela **Torre do Destino**, derrotando os inimigos e fortalecendo o personagem ao longo da jornada.

## ▶️ Como executar

1. Baixe ou clone este repositório.
2. Abra o projeto no **Visual Studio Code**.
3. Execute o arquivo JavaScript em um ambiente compatível com `prompt()`.
4. Siga as instruções apresentadas durante o jogo.

> **Observação:** como o jogo utiliza `prompt()`, ele precisa ser executado em um ambiente que ofereça suporte a essa função.
